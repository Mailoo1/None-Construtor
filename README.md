# Controlobra 🏗️

Aplicación móvil desarrollada para la gestión y control de obras de construcción.

**Controlobra** permite administrar personal, registrar materiales, llevar seguimiento del avance de la obra y centralizar toda la información importante en un solo lugar.

La idea nace a partir de una necesidad real observada en el sector de la construcción, donde muchos procesos aún se manejan de forma manual en cuadernos o documentos físicos. Esta aplicación busca modernizar esos procesos mediante herramientas digitales accesibles desde el celular.

---

## 🚧 Características principales

- 👷 Registro y gestión de personal
- 📅 Control de días trabajados
- 💰 Facturación del personal
- 🧱 Registro de llegada de materiales
- 📸 Captura y almacenamiento de fotografías
- ✅ Seguimiento de objetivos diarios, semanales y quincenales
- 🗂️ Gestión de planos y archivos importantes
- 📊 Evidencia fotográfica del progreso de la obra
- 📄 Exportación de reportes en PDF

### Backend & Servicios

### Exportación y Compartir Archivos

## ☁️ Servicios utilizados

### Firebase
Se utiliza para:
- Autenticación
- Base de datos
- Almacenamiento y sincronización en tiempo real

### Cloudinary
Se utiliza para:
- Almacenamiento de imágenes
- Optimización de fotografías
- Gestión multimedia de avances de obra

## 📦 Instalación

Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/controlobra.git
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el proyecto:

```bash
npx expo start
```

## 🎯 Objetivo del proyecto

El objetivo de **Controlobra** es facilitar la administración de obras de construcción mediante herramientas digitales simples, rápidas y accesibles desde dispositivos móviles.

La aplicación busca reducir el uso de procesos manuales, mejorar la organización y optimizar el seguimiento de proyectos de construcción.
